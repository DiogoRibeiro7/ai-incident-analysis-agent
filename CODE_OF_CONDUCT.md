# Code of Conduct

## Standards

This project expects respectful, technically focused collaboration. Good-faith
questions, bug reports, design critiques, and implementation disagreements are
welcome when they stay concrete and constructive.

Unacceptable behavior includes harassment, personal attacks, discriminatory
language, spam, threats, or publishing private information without permission.

## Enforcement

Maintainers may edit or remove comments, close issues, restrict participation,
or report abuse to GitHub when behavior disrupts the project or creates safety
risks.

Report conduct concerns privately through the security contact listed in
[SECURITY.md](SECURITY.md) when public reporting would be inappropriate.
